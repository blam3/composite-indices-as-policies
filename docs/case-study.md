# Case study: uncertainty in a resource-allocation ranking

## Decision question

If a hypothetical program funds census tracts above an SVI rank threshold,
how stable is the resulting list when the survey inputs are uncertain?
The case study concerns Louisiana and the CDC/ATSDR SVI 2022 edition.
It does not evaluate an observed grant program.

## Approach

1. Reconstruct the published index from ACS variance replicate tables, including
   rounding, ties, component sums, and missingness conventions.
2. Propagate survey-input uncertainty through the complete ranking pipeline,
   using a Gaussian perturbation model informed by the variance replicates.
3. Compare designs retaining or removing different covariance components and
   inspect a published-replicate sensitivity check without the Gaussian step.
4. Summarize rank intervals and threshold decisions. Keep leavers, entrants,
   and total label changes distinct to avoid double counting replacements.

## Archived finding

The [reference manifest](../analysis/louisiana/results/EXPECTED-RESULTS.json)
records exact agreement on **57,368/57,368** values and **57,918/57,918**
missingness cells (`deterministic.reproduction`), across **1,379** CDC tracts
(`deterministic.meta`). This validates reproduction of the index, not the
substantive validity of the index or the uncertainty model.

For the published top-decile set of **137** tracts, the archived simulation
reports **34.17 expected leavers**, **34.18 expected entrants**, and **68.35
expected label changes** (`monte_carlo.decisions_replicate.top_decile`).
The leaver rate is **24.94%**, not the symmetric difference divided by the
funded count. All these values trace to `code/07_decision_reliability.R` and
`code/11_expected_results.R` under the Louisiana analysis directory.

The median rank interval spans **29.25 percentile points**
(`monte_carlo.rank_stability.replicate.median_ci90_width`, generated by
`05_replicate_simulation.R` and emitted by `11_expected_results.R`).

## What this supports

Ranking uncertainty can translate into unstable threshold eligibility even when
the published index is reproduced exactly. A point ranking alone does not
communicate how certain an allocation list is under the assumed error model.

## What it does not support

These are simulation results conditional on model assumptions, not frequencies
from repeated real surveys. The analysis does not establish actual allocation
errors, individual-level relationships, the benefits of changing weights, or
transportability to another jurisdiction. Tract-level associations are
observational and descriptive. See [verification status](verification.md) for
archived claims that still require reconciliation.
